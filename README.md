# FinderPreset (Finder 프리셋)

**한국어** | [English](README.en.md)

> 이 앱은 Anthropic의 AI 어시스턴트인 Claude를 이용해 만들었습니다. 코드 작성, 빌드, 문서화를 Claude와 함께 진행했습니다.

Finder 폴더의 보기 설정을 프리셋으로 저장해 두고, Finder 우클릭 메뉴에서 바로 적용하는 macOS 앱입니다. 설정은 폴더마다 따로 저장되어 다른 폴더에 영향을 주지 않습니다.

- macOS 15 이상, macOS 언어가 한국어일 때 동작합니다.
- 테스트 완료: MacBook Pro 14 (M5, macOS 27.2)
- Apple의 인증(공증)을 받지 않은 앱이라 처음 실행할 때 경고가 뜹니다. [처음 실행](#2-처음-실행)을 참고해 주세요.

## 최신 버전: v1.0

- 첫 공개 버전
- 우클릭 → 보기 프리셋에서 프리셋을 골라 폴더에 바로 적용
- 하위 폴더까지 적용 (지금 있는 하위 폴더에 한 번만 적용)
- 현재 보기를 프리셋으로 저장
- 앱 창에서 프리셋 추가, 편집, 삭제, 순서 변경

변경 내역은 [CHANGELOG.md](CHANGELOG.md), 앱은 [최신 릴리스](https://github.com/nunnoo58/FinderPreset/releases/latest)에서 볼 수 있습니다.

## 프리셋에 담기는 항목

| 구분 | 항목 |
| --- | --- |
| 기본 | 보기 방식(아이콘, 목록, 계층, 갤러리), 정렬 기준 |
| 아이콘 보기 | 아이콘 크기, 텍스트 크기, 레이블 위치, 항목 정보, 아이콘 미리보기 |
| 목록 보기 | 아이콘 크기, 텍스트 크기, 상대적 날짜, 모든 크기 계산, 아이콘 미리보기 |
| 계층 보기 | 텍스트 크기, 아이콘, 아이콘 미리보기, 미리보기 열 |

정렬 기준은 없음, 자동 격자 정렬, 이름, 종류, 최근 사용일, 추가된 날짜, 수정일, 생성일, 크기, 태그 중에서 고릅니다. 없음과 자동 격자 정렬은 아이콘 보기에서만 적용됩니다.

## 설치

### 1. 앱 내려받기

1. [Releases](../../releases)에서 `FinderPresets-v<버전>.zip`을 내려받아 압축을 풉니다.
2. `FinderPresets.app`을 응용 프로그램 폴더로 옮깁니다.

### 2. 처음 실행

이 앱은 유료 Apple 개발자 인증서로 서명하거나 Apple의 공증을 받지 않고, 작성자가 직접 만든 인증서로 서명했습니다. 그래서 인터넷에서 받은 앱을 처음 열면 macOS가 실행을 막고 아래와 비슷한 경고를 띄웁니다.
~~맥을 쓴다고 다 부자가 아니라고~~
```
"FinderPresets"을(를) 열 수 없습니다.
Apple은 "FinderPresets"에 Mac에 손상을 입히거나 개인정보를 침해할 수 있는 악성 코드가 없음을 확인할 수 없습니다.
```

macOS 15부터는 우클릭 → 열기로도 이 경고를 넘길 수 없습니다. 아래 순서로 한 번만 허용하면 이후에는 경고 없이 열립니다.

1. 앱을 더블클릭하고, 경고 창에서 **완료**를 누릅니다. **휴지통으로 이동**은 누르지 않습니다.
2. 시스템 설정 → 개인정보 보호 및 보안으로 들어가 아래쪽 보안 항목까지 내립니다.
3. "FinderPresets"이(가) 차단되었다는 문구 옆의 **그래도 열기**를 누르고, 암호나 Touch ID로 확인합니다.
4. 다시 뜨는 창에서 **열기**를 누릅니다.

**그래도 열기**가 보이지 않으면 앱을 한 번 더 실행한 뒤 다시 확인합니다. 이 버튼은 실행을 시도하고 1시간 안에만 표시됩니다.

터미널에 익숙하다면 아래 명령으로 다운로드 표시(격리 속성)를 지워도 됩니다.

```
xattr -dr com.apple.quarantine /Applications/FinderPresets.app
```

앱은 이 저장소의 [Releases](../../releases)에서만 내려받아 주세요. 다른 곳에서 받은 파일은 같은 이름이어도 변조되었을 수 있습니다.

### 3. Finder 확장 켜기

앱 창 위쪽에 "Finder 확장이 꺼져 있어 우클릭 메뉴에 나타나지 않는다"라는 안내가 보이면 **확장 켜기**를 눌러 "Finder 프리셋"을 켭니다. 안내가 사라지면 Finder 우클릭 메뉴에 **보기 프리셋**이 나타납니다.

### 4. 권한 허용

처음 프리셋을 적용하면 확인 창이 뜹니다. 모두 허용해 주세요. 앱 본체와 Finder 확장이 각각 요청하므로, 앱에서 처음 적용할 때와 우클릭 메뉴로 처음 적용할 때 한 번씩 뜹니다.

- **자동화**: "Finder 프리셋"이 Finder와 System Events를 제어하려고 합니다 → 허용
- **손쉬운 사용**: 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 "Finder 프리셋"을 켭니다.

### 참고

- **업데이트**: 새 버전의 `FinderPresets.app`을 응용 프로그램 폴더에 덮어쓰면 됩니다. 프리셋은 그대로 남습니다.
- **확인 창이 뜨지 않거나 실수로 거부한 경우**: 터미널에서 아래 명령으로 권한을 초기화한 뒤 다시 적용합니다.
  ```
  tccutil reset AppleEvents com.nunnoo.FinderPresets
  tccutil reset AppleEvents com.nunnoo.FinderPresets.FinderSync
  tccutil reset Accessibility com.nunnoo.FinderPresets
  tccutil reset Accessibility com.nunnoo.FinderPresets.FinderSync
  ```
- **삭제**: 앱을 휴지통으로 옮기고, 프리셋 파일 `~/Library/Application Support/FinderPresets/`도 지웁니다. 이미 적용한 폴더의 보기 설정은 그대로 남습니다.

## 사용법

| 동작 | 방법 |
| --- | --- |
| 지금 보는 폴더에 적용 | 창의 빈 곳 우클릭 → 보기 프리셋 → 프리셋 선택 |
| 특정 폴더에 적용 | 폴더 우클릭 → 보기 프리셋 → 프리셋 선택 |
| 하위 폴더까지 적용 | 우클릭 → 보기 프리셋 → 하위 폴더까지 적용 → 프리셋 선택 |
| 현재 보기 저장 | 우클릭 → 보기 프리셋 → 현재 보기를 프리셋으로 저장… |
| 프리셋 편집 | 우클릭 → 보기 프리셋 → 프리셋 편집…, 또는 앱 실행 |

- 파일을 우클릭하면 그 파일이 들어 있는 폴더에 적용됩니다.
- 하위 폴더까지 적용은 그 시점에 있는 하위 폴더에 한 번만 복사합니다. 나중에 만든 폴더나 부모 폴더를 바꾼 내용은 따라가지 않습니다. 대상이 20개를 넘으면 먼저 확인 창이 뜹니다.
- 앱에서는 맨 앞 Finder 창을 기준으로 "현재 창에 적용", "현재 창에서 가져오기", "현재 Finder 창에서 새 프리셋"을 쓸 수 있습니다.

## 동작 원리

- 최근 macOS의 Finder는 AppleScript로 바꾼 정렬, 목록 열 표시, 배경색을 화면에 반영하지 않습니다. 그래서 두 방식을 섞어 씁니다.
  - AppleScript: 보기 방식, 아이콘·텍스트 크기, 레이블 위치, 미리보기 등 반영되는 항목
  - UI 스크립팅(System Events): 보기 → 다음으로 정렬 메뉴를 눌러 정렬하고, 보기 옵션의 "항상 ○○ 보기로 열기"를 켭니다.
- Finder는 "항상 ○○ 보기로 열기"가 꺼진 폴더의 보기 방식과 정렬을 기억하지 않고 마지막에 쓴 보기를 따라갑니다. 이 옵션을 켜야 설정이 폴더별로 저장됩니다.
- 닫힌 폴더는 잠깐 열어서 적용한 뒤 닫습니다. 처음 다루는 폴더나 보기 방식이 바뀌는 폴더는 Finder가 첫 적용 값을 저장하지 않아 한 번 더 적용합니다.
- 프리셋은 `~/Library/Application Support/FinderPresets/presets.json`에 저장되고, 앱과 Finder 확장이 함께 씁니다.

## 알려진 한계

- Finder 메뉴 이름("보기", "다음으로 정렬", "보기 옵션")을 한국어로 찾기 때문에, macOS 언어가 한국어가 아니면 정렬과 폴더별 저장이 동작하지 않습니다.
- 적용하는 동안 대상 폴더 창이 앞으로 오고 보기 옵션 창이 잠깐 나타납니다. 그동안 Finder를 조작하면 다른 창에 적용될 수 있습니다.
- 폴더 하나에 3\~6초 걸립니다. 하위 폴더가 많으면 그만큼 오래 걸립니다.
- 정렬 방향은 Finder 기본값을 따릅니다. 날짜와 크기는 큰 값부터, 이름은 가나다순입니다.
- 목록 보기의 열 표시와 배경색은 지원하지 않습니다.
